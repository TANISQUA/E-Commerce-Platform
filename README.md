# 🛒 E-Commerce Platform

A modern and responsive E-Commerce Platform built using **HTML, CSS, and JavaScript**. This project provides users with an intuitive online shopping experience through a clean interface, product browsing, shopping cart functionality, and responsive design.

## 🌐 Live Demo

🔗 **Website:** https://tanisqua.github.io/E-Commerce-Platform/

## ✨ Features

- Responsive design for desktop, tablet, and mobile devices
- Modern and user-friendly interface
- Product browsing and catalog display
- Shopping cart functionality
- Interactive user experience with JavaScript
- Fast and lightweight frontend implementation
- Deployed using GitHub Pages

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Git & GitHub
- GitHub Pages

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/Tanisqua/E-Commerce-Platform.git
```

### Navigate to the Project Directory

```bash
cd E-Commerce-Platform
```

### Run the Project

Open the `index.html` file in your preferred web browser.
